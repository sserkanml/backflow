# Upgrading to `backflow.io/v1beta1` (0.18)

This guide is superseded by **[Upgrading to 1.0](operations/upgrade-1.0.md)**, which covers the way from 0.17 and earlier (`v1alpha1`) and from 0.18.x
(`v1beta1`) to 1.0 (`backflow.io/v1`), for Helm, kustomize and OLM. The migration of 0.17 to 0.18 and the one of 0.17 to 1.0 are the same
steps; the tool ends in `v1` now. Do not follow an older copy of this page.
