## Kustomize

Each row is one change made in the cluster to a resource built from an overlay of `testdata/kustomize`, mapped back to its files with the production Kustomize mapping path (the renderer is `kustomize build`, v5.8.1 as in Argo CD; `make kustomize` installs it). The overlays share one base; `kustomize-dev-images` is the `dev` overlay with `spec.source.kustomize.images` set on the Application.

Modes: **default** is a policy with no options (`spec.kustomize.addPatches` on, `editBases` off); **editBases** also allows edits of files outside the Application's path; **no-addPatches** turns `addPatches` off, so a value that no setting, patch or file holds stays Unmapped. The bracket after an edit is its tier.
